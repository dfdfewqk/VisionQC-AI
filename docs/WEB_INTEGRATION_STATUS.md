# VisionQC AI — 웹 화면 통합 상태

## 이번 웹 통합

- 기존 단순 ONNX 테스트 화면을 작업대/기록/품질 통계/LOT·제품 관리 메뉴로 교체한다.
- `openBrowserInspectionService()`를 사용하여 업로드 → 품질 게이트 → PatchCore 추론 → 원본·PNG 히트맵 IndexedDB 기록 → 상세 화면을 하나의 사용자 동작으로 연결한다.
- Chrome의 HTTPS/localhost 카메라 촬영(권한 요청, 기기 목록/변경, 스트림 종료)과 촬영 후 검사 요청을 연결한다. 업로드 대체 수단을 제공한다.
- 사용자가 원본 사진을 드래그해 ROI를 선택할 수 있다. 선택하지 않으면 기존 중앙 크롭 사전 검증이다.
- 검사 기록 목록·상세·삭제, 작업자 최종 판정 수정 이력, AI/인간 통계, 검사 대기열과 수동 재개, LOT·제품 등록 및 제품 연결 UI를 기존 API로 연결한다.
- 사용자·데모 데이터는 별도의 필터로 보여 준다. 원본 사진은 서버 업로드하지 않는다.

## 남은 검증/기능

- GitHub Actions 통과와 실제 브라우저 모델 다운로드/ONNX 추론 성공은 별개다.
- 현장 이미지로 정상/결함 샘플을 이용한 정확도 평가·보정과 독립 검증은 아직 완료되지 않았다. 따라서 AI 결과는 확인 필요/후보이며 작업자 최종 판정과 분리한다.
- **학습된 너트 객체 탐지 모델을 이용한 자동 ROI 탐지**는 아직 연결되지 않았다. 수동 드래그/중앙 크롭은 자동 탐지와 동일하지 않다.
- 실제 Windows Chrome의 카메라 권한/기기 전환, 브라우저 종료 후 큐 복구·메모리·네트워크/캐시 동작 실측은 별도 테스트가 필요하다.
- LOT 확정 제품 수/재작업·LOT 마감·보고서·백업 등 후속 확정 기능은 이번 웹 1차 통합 범위가 아니다.

## 실행

1. Node.js 설치 후 프로젝트 폴더에서 `npm install`, `npm run dev`.
2. 터미널에 뜨는 `http://localhost:5173/` 주소를 Chrome에서 열기.
3. 상단에서 사용자·체험 기록 선택, 사진 업로드 후 ROI 선택, `AI 검사 및 기록 저장`으로 검사.
4. 검사 기록·작업자 확정·통계·LOT 화면을 조회한다.
5. 촬영을 이용하려면 `카메라로 촬영` → 브라우저 권한 허용 → `촬영 후 바로 검사`.
