# VisionQC AI v1.0 — 설계 통합 점검 (2026-10-28)

**설계 상태:** 단계 1~95 A안 확정. 신규 기능 제안은 보류. 기존 합의는 임의로 변경·삭제하지 않음. 구현 우선순위는 48·58단계 준수.

## 제품의 단일 목표

취업 포트폴리오용 공개 URL에서 금속 너트 사진 촬영/업로드 → 너트 탐지/ROI 보정 → 기존 학습된 PatchCore의 브라우저 로컬 추론 → AI 3단계 후보 판정/원본 좌표 히트맵 → 작업자 최종 검토 → 이력/품질 통계. **실측되지 않은 정확도나 실제 산업용 신뢰성을 주장하지 않는다.**

## 확정 설계 구성

1. **프런트엔드·배포 (14~24, 49, 60~63, 65~71):** React+TS+Vite, Vercel, 데스크톱 우선, 카메라 촬영 즉시 검사, 이미지 업로드, 자동 ONNX 다운로드/캐시, CPU WASM 기본, 검증 후 WebGPU, `main`/`develop`/기능별 브랜치, 공개 검증 및 롤백.
2. **모델·품질 제어 (1~5, 21~35, 50~52, 59, 64):** 공개 PatchCore + 학습된 객체 탐지 모델/OpenCV.js 보조. 정상 후보/확인 필요/이상 후보는 AI의 추정이며 최종 작업자 판정과 분리. 부적합 이미지·검증되지 않은 부품/촬영 환경은 보류. 공개 모델의 실제 성능은 재측정해야 하며 test-set 최적화 임계값을 직접 확정 성능이라 부르면 안 됨.
3. **이미지·연속 작업 (25~27, 36~40, 66~69, 79~80):** 원본·좌표·변환 보존, 사용자가 ROI 조정, 이미지 내 여러 너트 중 선택 검사, 원본 사진 한 건과 ROI별 검사 별도. 순차 검사+대기 1장, 이미지 오류는 개별 처리·시스템 오류는 전체 일시정지, 브라우저 종료 후 수동 재개, 동일 브라우저 프로필에서 검사 탭 하나만 활성화, 동일 이미지의 원검사/재검사는 연결.
4. **저장·개인정보·보고 (6, 7~20, 41~47, 53~57):** 웹 버전에서 SQLite는 브라우저 IndexedDB로 대체. 원본·히트맵·판정·변경 이력 자동 저장, 데이터 출처 분리. API 키는 Vercel 서버 환경변수, DeepSeek는 관리자 인증 후 명시 호출·필요 시 이미지 전송 동의. 사용자가 삭제하면 관련 데이터 함께 삭제; 이미 다운로드한 외부 백업은 별도. 버전 표시된 암호화 백업과 안전한 복원. 보고서는 사실·추정을 분리.
5. **검사 품질·LOT (72~94):** AI/사람 판정 구분, 작업자 식별명·사유·수정 이력, 검사일 기준 추이·표본 불량률, 실제 검사 제품 고유 ID와 이미지·검사 횟수 구분, LOT 전체 생산량 선택값, 미확정 검사율 표시 금지. 복수 방향 검사 시 어느 하나 확정 불량이면 제품 불량으로 통합하되 재작업 후 명시적 재검사 승인으로 현재 상태 전환 가능. 최초 불량 이력·현재 상태·후속 조치/폐기·LOT 마감/재개방·조건부 마감/최종 마감 통계와 보고서 버전 보존.

## 발견된 충돌·구현상 주의점과 정리

- **저장소 변경:** 초기에 언급된 로컬 SQLite, Windows Credential Manager, Windows 전용 앱은 이후 웹 전환 결정으로 대체되었음. 구현은 IndexedDB와 서버리스 비밀 관리 기준.
- **동일 이미지와 여러 너트:** 한 원본 해시만으로 검사를 1개로 취급하면 80단계와 충돌. 식별 단위는 `원본 이미지 ID / ROI 또는 제품 ID / 검사 실행 ID`. 동일 이미지 파일 재업로드는 중복 감지하되, 다른 ROI는 독립 고유 검사 가능.
- **불량 통계 분모:** 'AI 이상 후보 비율'과 '작업자 확정 불량률', 그리고 '확정된 고유 제품 불량률'은 서로 다른 지표. 검토 대기, 미확정 제품 식별, 체험 데이터는 해당 지표에서 누락/제외 내역을 분리 표시해야 함.
- **87단계의 정상 전환과 86단계의 하나라도 불량:** 단순한 최신 검사 자동 덮어쓰기 금지. 과거 불량 근거는 유지하되, 정상 전환을 위한 명시적 재작업/정정 승인 사건이 있을 때만 현재 제품 통합 상태가 바뀜.
- **immutable 이력과 삭제 요청:** 과거 검사 기록은 일반 수정/재분석에서 불변. 단, 사용자가 명시적으로 검사 삭제를 요청하면 56~57단계에 따라 연관 데이터 삭제. 저장된 외부 백업까지 지울 수 없음.
- **마감과 조건부 마감:** 일반 마감은 미완료 검사 없이. 미완료 시 예외 사유를 기록한 조건부 마감만 가능; 후속 처리 시작 시 LOT 재개방, 수동 최종 마감 후 새 스냅샷. 통계 스냅샷은 재계산하여 덮어쓰지 않음.
- **ROI/히트맵 좌표:** 자동 탐지·기하학적 정규화(이동/회전/크롭)의 역변환을 누락하면 원본 좌표가 틀림. 변환 체인과 확인 가능한 정확도를 반드시 저장.
- **브라우저 모델 실행:** HF에 `backbone.onnx`, `knn_metal_nut.onnx`, `thresholds.json`이 존재하지만 특정 브라우저/장치에서 실제 로딩·성능은 별도 검증 대상. 서드파티 OCR/객체 탐지까지 실제 활용 가능한지는 아직 미검증.
- **라이선스:** 해당 MVTec AD 파생 모델은 CC BY-NC-SA 비상업적 제한. 기업 상용 품질검사에 바로 이용할 수 없음. 샘플 배포권 별도 확인.
- **7일 범위:** 95개 확정 요구 전체를 7일 안에 출시 완료했다고 간주하지 않는다. 58단계의 첫 공개 핵심 기능을 먼저 구현하고, 나머지는 누락 없이 후속 백로그로 관리.
