# VisionQC 개발 실행 순서 및 수락 기준

## D0 — 설계 통합 및 베이스 코드 (현재)
- [x] 1~95단계 확정 사항을 인덱스·통합 점검 문서로 정리
- [x] React/Vite/TypeScript 소스, ONNX 참조 추론 함수, 수치/좌표 테스트
- [x] 순수 수치·모델 출력 계약 자동 테스트 실행(12개 통과)
- [ ] 실제 npm 의존성 설치·빌드 (현재 실행 환경 인터넷 차단)
- [ ] GitHub 저장소 접근 확인 후 코드 업로드 (사용자는 생성했다고 알렸으나 연결 계정의 조회에서는 404)

## D1 — 모델 런타임 적합성
- [ ] 웹 브라우저에서 실제 backbone 및 knn_metal_nut 세션 생성
- [ ] 실제 정상/불량 이미지를 이용해 예측 점수·히트맵 검증
- [ ] 메타데이터/임계값/출력 텐서 구조 검증; 오류 처리와 재현 로그
- [ ] 모델 파일 무결성 및 라이선스 확인
**수락:** 실제 모델로 추론이 동작하고 오류/성능 로그가 확인됨. 테스트 통과만으로 정확도를 주장하지 않음.

## D2 — 너트 자동 탐지와 ROI
- [ ] 실제 경량/범용 탐지 모델 중 검증된 것 채택(OWL-V2 포함 후보)
- [ ] OpenCV.js 단순 배경 보조, 다중 너트 영역 확인
- [ ] 수동 ROI 조정, 원본 사진·정규화 변환 저장
**수락:** 사진 속 너트를 실제 탐지, 실패 시 사람이 보정 가능.

## D3 — 검사 UI · 촬영 · 후보 판정
- [ ] 카메라 촬영, 업로드, 촬영 후 자동 검사, 이미지 품질 게이트
- [ ] 실제 데이터에서 보정한 정상 후보/확인 필요/이상 후보 판정
- [ ] 원본 좌표 히트맵, 로딩/오류 표시, 접근성/모바일 레이아웃
- [ ] 순차 검사/대기 1장, 종료·취소 복구
**수락:** 실제 사진 한 장으로 일련의 검사 경험이 동작.

## D4 — 기초 이력 · 시험 · 공개 배포
- [ ] IndexedDB 원본·ROI·결과 보존, 중복 방지, 기록 조회
- [ ] GitHub CI 빌드·단위/통합·브라우저 테스트
- [ ] Vercel Preview -> main production 공개, 실측 품질/성능 보고
**수락:** 공개 URL로 처음 방문한 사람이 실제 AI 검사를 수행. 핵심 기능 장애면 배포 차단.

## 이후 기존 확정 기능(후속 개발 단계)
작업자 판정 감사 로그, 고급 이력·통계, 관리자 DeepSeek, PDF/CSV, 암호화 백업, 버전별 재분석, LOT 전체 생애주기(1~95단계 인덱스 참조)를 순차 통합.
