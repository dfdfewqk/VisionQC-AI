# VisionQC AI — 사진 속 너트 영역 자동 제안과 공개 전 검증 경계

## 현재 연결 상태

1. `src/detection/nutRoiCandidates.mjs`는 **학습된 객체 탐지 모델이 아니다**. 이미지 테두리의 균일성을 확인한 후 대비로 구분되는 전경 윤곽을 추출하여 ROI 후보(최대 5개)를 제안한다.
2. 후보가 없거나 배경이 복잡하면 **아무것도 추측하지 않는다**. 사용자가 사진 위를 드래그하거나 좌표/회전을 직접 설정한다.
3. 제안된 ROI는 **사용자가 직접 확인·변경**할 수 있다. 모델 적합성/현장 정확도 인증은 수행하지 않으며 PatchCore도 여전히 최종 정상·불량을 선언하지 않는다.
4. 촬영한 사진은 원본 EXIF 방향 좌표로 ROI를 변환하여 검사하고 이상 점수/히트맵/검사기록을 IndexedDB에 저장한다. 자동 제안 결과는 물리적 제품이나 고유 너트를 인증하지 않는다.
5. **일반적인 복잡한 배경·밀집 너트·반사광·원근 왜곡**에서도 정확히 탐지한다고 주장하지 않는다.

## 검증 후 교체해야 할 탐지 구성요소

- 1~95단계 확정 정책의 '사전학습 객체 탐지 AI + OpenCV 보조'를 완성하려면 로컬 또는 브라우저 실행 가능한 **실제 너트용 학습된 탐지 모델 가중치**를 선정해 권한/라이선스 확인 후 무결성 핀 고정·출력 좌표 규격·원본 변환을 구현해야 한다.
- 공개 후보 예: Roboflow Universe에는 nut-detection 모델이 있으나 **호스팅 API는 사진 외부 전송이 발생할 수 있다.** 이 프로젝트는 기본 사진 로컬 처리 정책 때문에 그 엔드포인트에 자동 업로드하지 않는다.
- 모델 없이 검증되지 않은 HTTP 탐지 호출이나 가짜 탐지 결과를 반환하지 않는다.
- 실제 너트 사진과 라벨을 확보해 탐지 precision/recall, 복수 너트, 미탐지/오탐 및 바운딩 박스 정확도, 실제 PatchCore 적합성을 검증하기 전에는 제품용 자동 검사 완료로 표기하지 않는다.
